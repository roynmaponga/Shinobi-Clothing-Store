# SHINOBI Clothing Store

A collaborative clothing e-commerce application developed using **C#, ASP.NET, SQL, Git, and GitHub**.

The project was developed as part of a university Agile Software Development team project, with functionality organised around **Users, Products, Orders, and Sales**.



## Project Overview

**SHINOBI Clothing Store** is a database-driven clothing store application developed collaboratively by a team of four developers.

The application demonstrates software engineering principles including:

- Object-Oriented Programming
- Database-driven application development
- CRUD functionality
- Modular software development
- Automated testing
- Debugging and validation
- Git and GitHub version control
- Agile/Scrum development
- Team collaboration
- Software Development Life Cycle (SDLC)

The system is divided into four main functional areas:

- **Users**
- **Products**
- **Orders**
- **Sales**

## Core Functionality

### Users

The Users component manages user-related functionality within the application.

My contribution included directly implementing the **Users functionality**, working with user-related data and database operations, testing the functionality, and integrating the component with the wider application.

### Products

The Products component provides functionality for managing clothing products within the application.

### Orders

The Orders component handles order-related functionality within the system.

### Sales

The Sales component provides functionality related to sales information and management.

## Testing

Testing was an important part of the development process.

The repository contains dedicated testing projects for the different areas of the application:

- `TestingUsers`
- `TestingProducts`
- `TestingOrders`
- `TestingSales`

These projects were used to test functionality, identify issues, and validate changes during development.

Testing and debugging were carried out throughout the development process rather than being left until the end of the project.
